🌊 Marine Life Explorer

Documentation

App Overview

Marine Life Explorer is an educational Progressive Web App built with HTML5, CSS, and JavaScript. It allows users to learn about ocean creatures through images, descriptions, and audio clips. The app can be installed on any device and works offline.

Features

  • Dropdown menu dynamically populated from a JSON file
  • Displays image, description, and audio for each animal
  • Installable on desktop and mobile devices
  • Works offline using a service worker
  • Responsive design that works on all screen sizes

File Structure

  • index.html — Main app page
  • style.css — All styling for the app
  • app.js — JavaScript that loads JSON and powers the app
  • data.json — Stores all animal data
  • manifest.json — Makes the app installable
  • sw.js — Service worker for offline functionality
  • images/ — All animal images
  • audio/ — All animal audio files

How to Modify the JSON File

To add a new animal to the app, open data.json and add a new entry inside the marineLife array following this format:


{
  "title": "Animal Name",
  "description": "Write a description of the animal here.",
  "image": "images/yourimage.jpg",
  "audio": "audio/youraudio.mp3"
}

Then upload the matching image to the images/ folder and the audio file to the audio/ folder. The app will automatically show the new animal in the dropdown menu.
