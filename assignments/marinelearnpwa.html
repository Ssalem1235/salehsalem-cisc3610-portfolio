About the App

Marine Life Explorer is an educational Progressive Web App (PWA) built with HTML5, CSS, and JavaScript. It allows users to learn about fascinating ocean creatures through images, descriptions, and audio clips. The app can be installed on any device and works offline thanks to a service worker.

How to Install

💻 On Desktop (Chrome)
  1. Open the app in Google Chrome
  2. Look for the install icon in the address bar (a computer with a + sign)
  3. Click it and select Install
  4. The app opens as its own window on your computer
📱 On Mobile (Android / iPhone)
  1. Open the app in your mobile browser
  2. Tap the browser menu (three dots or share icon)
  3. Select Add to Home Screen
  4. The app icon will appear on your home screen

Documentation

File Structure
  • index.html — Main app page
  • style.css — All styling for the app
  • app.js — JavaScript that loads the JSON and powers the app
  • data.json — Stores all animal data (title, description, image, audio)
  • manifest.json — Makes the app installable as a PWA
  • sw.js — Service worker that enables offline functionality
  • images/ — All animal images
  • audio/ — All animal audio files
How to Add a New Animal

To add a new animal to the app, open data.json and add a new entry inside the marineLife array following this format:

{
  "title": "Animal Name",
  "description": "Write a description of the animal here.",
  "image": "images/yourimage.jpg",
  "audio": "audio/youraudio.mp3"
}

Then upload the matching image to the images/ folder and the audio file to the audio/ folder. The app will automatically show the new animal in the dropdown menu.
